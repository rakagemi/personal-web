## ⚙️ Environment Variables

Copy `.env.example` and rename it to `.env.local`:

```bash
cp .env.example .env.local
```

Then fill in the values below:

```env
# ┌─────────────────────────────────────────────┐
# │             🔧 APP CONFIGURATION             │
# └─────────────────────────────────────────────┘

# Toggle Maintenance Mode (true | false)
NEXT_PUBLIC_MAINTENANCE_MODE=false

# ┌─────────────────────────────────────────────┐
# │         📬 WEB3FORMS — CONTACT FORM          │
# │         https://web3forms.com                │
# └─────────────────────────────────────────────┘

# Your Web3Forms Access Key
NEXT_PUBLIC_FORM_DATA_KEY=your_web3forms_access_key_here

# Web3Forms API Endpoint
NEXT_PUBLIC_FORM_DATA_ENDPOINT=https://api.web3forms.com/submit
```

> 💡 Get your free API key at [web3forms.com](https://web3forms.com) — no backend needed!

## 🛠️ Getting Started

### Prerequisites

Make sure you have **Node.js ≥ 18** or **Bun ≥ 1.x** installed.

### Install Dependencies

```bash
# Using npm
npm install

# Using bun (recommended — faster!)
bun install
```

### Run Development Server

```bash
# Using npm
npm run dev

# Using bun
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. 🎉

> The page auto-updates as you edit `app/page.tsx` — powered by Next.js Fast Refresh.

## 🌐 Deployment

The easiest way to deploy is via **[Vercel](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app)**:

1. Push your code to GitHub
2. Import the repo on Vercel
3. Add all `.env` variables in **Project Settings → Environment Variables**
4. Hit **Deploy** 🚀
